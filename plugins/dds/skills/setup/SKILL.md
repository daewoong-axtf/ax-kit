# dds:setup

프로젝트에 Daewoong Design System을 설정한다.

절차는 이 스킬에 복사해 두지 않는다. 같은 플러그인의 `dds` 스킬 원문(이 파일 기준 `../dds/SKILL.md`)을 읽고 "1. 설정" 절을 처음부터 끝까지 그대로 따른다. 그 문서의 "하지 않는 것"도 함께 지킨다.

원문을 읽지 못하면 절차를 지어내지 않는다. 읽지 못한 이유를 사용자에게 알리고 멈춘다.
