# dds:check

화면을 Daewoong Design System 기준으로 점검한다. 사용자가 가리킨 화면을 보고, 없으면 이번 작업에서 바뀐 화면을 본다.

절차는 이 스킬에 복사해 두지 않는다. 같은 플러그인의 `dds` 스킬 원문(이 파일 기준 `../dds/SKILL.md`)을 읽고 "4. 점검" 절을 처음부터 끝까지 그대로 따른다. 그 문서의 "하지 않는 것"도 함께 지킨다.

점검이 끝나면 같은 문서의 "5. 보고"대로 보고한다.

원문을 읽지 못하면 절차를 지어내지 않는다. 읽지 못한 이유를 사용자에게 알리고 멈춘다.
